Lisperpaw Icon Study

Tree Tiered に猫の前足を重ねた候補

現在の Tree Tiered を起点に、Lisperpaw の「最初の一歩」と猫の前足を重ねた 10 案を先頭に追加しました。 その下には、従来の S式ベース候補 40 案も残してあるので、paw 融合案と元の方向性をそのまま見比べられます。

現行に近い: Paw Tiered と Paw Pixel。今の favicon の骨格をほぼ残したまま猫要素を足しています。
意味を乗せやすい: Paw Step と Paw Nest。「最初の一歩」と「やさしく迎える」意味を載せやすいです。
ブランド寄り: Paw Bloom と Paw Crown。favicon より header mark や SNS で映えやすい方向です。
