## 数学関数

```lisp
(abs -5)       ; => 5
(max 3 7 2)    ; => 7
(min 3 7 2)    ; => 2
(expt 2 10)    ; => 1024
(sqrt 144)     ; => 12
(mod 17 5)     ; => 2
```

### 問題
以下の計算結果をそれぞれ出力してください：
1. -42 の絶対値
2. 2 の 8 乗
3. 17 を 5 で割った余り
